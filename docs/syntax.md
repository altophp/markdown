# Syntax

Syntax extensions add author-facing Markdown constructs to a trusted factory
profile. Enable only the constructs accepted by the document format.

## Extensions

- [Paired delimiters](syntax/paired-delimiters.md): define safe inline delimiter pairs.
- [Smart punctuation](syntax/smart-punctuation.md): replace quotes, dashes, and ellipses.
- [Highlight](syntax/highlight.md): mark inline text with paired delimiters.
- [Description lists](syntax/description-lists.md): render terms and definitions.
- [Footnotes](syntax/footnotes.md): connect references to endnotes.
- [Tabs](syntax/tabs.md): group nested content into accessible panels.
- [Mentions](syntax/mentions.md): resolve application-specific references.
- [Attributes](syntax/attributes.md): attach constrained attributes to elements.

Each guide shows installation, configuration, Markdown input, HTML output,
options, and its security boundary.
